ЛР6. Вариант 20. Взаимодействие с ClickHouse с помощью Python

Предметная область, схема, исходные записи и десять аналитических запросов
соответствуют ЛР5. Каждый запрос вынесен в отдельную функцию в queries.py.

Требования: Python 3.12 и доступный сервер ClickHouse.

Запуск из этой папки в PowerShell:
  python -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
  Copy-Item .env.example .env
  .\.venv\Scripts\python.exe lab.py

В .env задаются адрес, HTTP-порт, имя пользователя, пароль и имя базы.
Порт 18123 соответствует пробросу порта учебного контейнера; стандартный
HTTP-порт ClickHouse — 8123. Укажите порт установленного у вас сервера.
Учебные параметры localhost:18123, default / 0000 взяты из методички.

Программа создаёт базу furniture_factory_lr6 и шесть таблиц MergeTree,
вставляет данные из sample_data.json только в пустые таблицы и выполняет
10 запросов. При повторном запуске заполненные таблицы не меняются.
Для непустой базы с другими данными результаты будут отличаться от отчёта.
Для воспроизведения отчёта используйте новое имя базы:
  .\.venv\Scripts\python.exe lab.py --database furniture_factory_lr6_copy

Файлы results/run.txt и results/results.json содержат фактический вывод
и структурированные результаты. В results также сохраняются два графика.
Запуск без графиков: python lab.py --no-charts
Папку вывода можно изменить: python lab.py --output results_other

Содержание проекта:
  lab.py             подключение, создание, заполнение, вывод, диаграммы
  queries.py         10 SQL-запросов в отдельных функциях
  schema.py          определения шести таблиц
  sample_data.json   исходные данные из ЛР5
  .env.example       пример параметров подключения
  requirements.txt   зависимости
  results/           результаты реального выполнения

В запросе о незавершённых заказах используется контрольная дата 01.05.2026
из ЛР5. Она фиксирована для воспроизводимости и не обозначает текущую дату.
В денежных вычислениях используются Decimal; суммы не переводятся во float
до построения графиков. Выручка включает только завершённые заказы.
